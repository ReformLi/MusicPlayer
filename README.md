## 需求文档：本地音乐播放器 (Final)

### 1. 概述

一款纯本地音乐播放器，支持扫描手机存储中的音频文件，提供完整的播放控制、歌词显示、播放队列、播放历史、收藏、定时停止、主题跟随、高亮当前播放等功能。界面采用侧边栏导航，底部 MiniPlayer 全局控制（仅主页显示），播放页拥有按比例分配的布局，稳定不挤压。

---

### 2. 功能模块

#### 2.1 媒体扫描

- **全盘扫描**：扫描系统媒体库中所有音频文件，使用 `MediaStore.VOLUME_EXTERNAL`，支持 Android Q+。
- **自定义文件夹扫描**：用户选择文件夹后，递归扫描其内所有音频文件，支持 SAF，并能自动匹配同目录下的封面图片和歌词文件。
- **扫描结果预览**：显示扫描进度（实时歌曲计数），按文件夹分组展示歌曲数量，支持多选目录后确认添加。支持增量更新（保留自定义字段），也可在设置中「重置歌曲库」完全清空重建。
- **扫描入口**：主页面右上角菜单提供「全盘扫描」和「自定义扫描」。
- **文件格式支持**：mp3, flac, wav, aac, ogg 等。

#### 2.2 歌曲管理

- **主页歌曲列表**：展示所有歌曲，支持实时搜索过滤，当前播放项高亮（粉红加粗文字 + 淡粉背景，去掉阴影，保留圆角），暂停/恢复均保持高亮。
- **歌曲操作**：每首歌曲右侧菜单提供「删除」「歌曲信息」「收藏」。
- **空状态提示**：无歌曲时显示引导文字。
- **音乐库**：侧边栏独立页面，展示所有歌曲，支持搜索，点击进入歌曲详情页，可编辑标题、艺术家、专辑，查看文件信息（类型、时长、大小、路径、添加日期），修改封面/歌词，收藏开关。
- **收藏功能**：侧边栏「我的最爱」显示收藏歌曲，支持搜索，点击播放并设队列为收藏列表，菜单仅显示「取消收藏」和「歌曲信息」。

#### 2.3 播放控制

- **播放服务**：前台 Service，支持后台播放及锁屏/通知栏控制（MediaStyle 通知），适配 Android 14+ 前台服务类型。
- **播放界面**：
  - 按屏幕高度比例分配：封面 30%，歌曲信息 8%，歌词 20%，进度条+时间 5%，按钮栏 10%，其余为边距，确保所有元素一屏显示。
  - 专辑封面、歌曲标题/艺术家、进度条（带时间标签格式化）、播放/暂停、上下首。
  - 播放模式切换：列表循环/单曲循环/随机播放，切换时显示 Toast 提示当前模式。
  - 定时停止：可选时间，倒计时显示。
  - 更多菜单：播放队列弹窗、定时停止、歌词字体大小调节。
  - 歌词同步：自动匹配 .lrc 文件，滚动高亮，字体大小可调。
- **MiniPlayer**：仅主页显示，点击进入播放界面，暂停时仍保留，封面、标题、艺术家显示。
- **播放状态记忆**：退出时保存当前歌曲、进度、播放模式；重新打开自动恢复但不自动播放，进度条位置正确显示。

#### 2.4 播放队列

- 弹框样式：顶部留 30%，左右下留 10%，深色圆角背景。
- 标题栏显示模式图标、名称、歌曲数量（单曲循环不显示），右上角清空按钮。
- 歌曲列表显示歌名+艺术家，可删除，点击播放，当前项高亮绿色加粗。
- 底部关闭按钮，点击外部也可关闭。

#### 2.5 播放历史

- 自动记录播放时间。
- 历史列表按时间倒序，点击查看信息（不播放）。
- 单条滑动删除（带撤销），右上角菜单清空全部（带确认）。

#### 2.6 设置

- **缓存管理**：显示封面缓存大小，可清除。
- **重置歌曲库**：清空所有歌曲、历史，停止播放。
- **帮助与关于**：待扩展。

#### 2.7 界面交互

- 侧边栏导航：主页、音乐库、我的最爱、播放历史、设置。
- 主页左上角抽屉图标，其他页面返回箭头。
- 返回键：主页二次确认退出；播放页返回直接回到主页；其他正常返回。
- MiniPlayer 仅主页可见，进入播放页、扫描结果页等自动隐藏。
- 主题跟随：亮色/暗色模式自动适配，卡片背景、文字颜色使用主题属性。

#### 2.8 数据与性能

- Room 数据库，版本 1（正式版）。
- 封面/歌词缓存分离，增量扫描保护用户自定义数据。
- 数据库升级使用 Migration，避免破坏式迁移。
- 进度条刷新间隔 100ms，丝滑流畅。

---

### 3. 技术栈

- Kotlin + MVVM + ViewBinding + Navigation + Material Design
- Room + MediaPlayer + Coil + 自定义 LRC 解析
- MediaStore（全盘扫描）+ SAF（自定义扫描）
