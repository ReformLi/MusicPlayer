## 需求文档：本地音乐播放器

### 1. 概述

一款纯本地音乐播放器，支持扫描设备存储中的音频文件，提供完整的播放控制、歌词显示、播放队列、播放历史、收藏、定时停止、自定义封面/歌词等功能。界面采用侧边栏导航，底部 MiniPlayer 全局控制。

### 2. 功能模块

#### 2.1 媒体扫描

- **全盘扫描**：扫描系统媒体库中所有音频文件。
- **自定义文件夹扫描**：用户选择文件夹后，递归扫描其内所有音频文件，支持 SAF，并能自动匹配同目录下的封面图片和歌词文件。
- **扫描结果预览**：按文件夹分组展示歌曲数量，支持多选目录后确认添加。支持增量更新（保留自定义字段），也可在设置中「重置歌曲库」完全清空重建。
- **扫描入口**：主页面右上角菜单提供「全盘扫描」和「自定义扫描」。
- **文件格式支持**：mp3, flac, wav, aac, ogg 等。

#### 2.2 歌曲管理

- **歌曲列表**（主页）：展示所有歌曲，支持实时搜索过滤。
- **歌曲操作**：每首歌曲右侧菜单提供「删除」「歌曲信息」「收藏」。
- **空状态提示**：无歌曲时显示引导文字。
- **音乐库**：点击进入歌曲详情页，可编辑标题、艺术家、专辑，查看文件信息，修改封面/歌词，收藏开关。

#### 2.3 播放控制

- **播放服务**：前台 Service，支持后台播放及锁屏/通知栏控制（MediaStyle 通知）。
- **播放界面**：
  - 专辑封面、歌曲信息、进度条、播放/暂停、上下首。
  - 播放模式切换：列表循环/单曲循环/随机播放。
  - 定时停止：可选时间，倒计时显示。
  - 更多菜单：播放队列弹窗、定时停止、歌词字体大小调节。
  - 歌词同步：自动匹配 .lrc 文件，滚动高亮，字体大小可调。
- **MiniPlayer**：仅主页显示，点击进入播放界面，暂停时仍保留。

#### 2.4 播放队列

- 弹框样式：顶部留空，左右下留白，深色圆角背景。
- 标题栏显示模式图标、名称、歌曲数量，右上角清空按钮。
- 歌曲列表显示歌名+艺术家，可删除，点击播放，当前项高亮。
- 底部关闭按钮，点击外部也可关闭。

#### 2.5 播放历史

- 自动记录播放时间。
- 历史列表按时间倒序，点击查看信息，不播放。
- 单条滑动删除（带撤销），右上角菜单清空全部（带确认）。

#### 2.6 我的最爱

- 侧边栏页面，展示收藏歌曲，支持搜索。
- 点击播放并设队列为收藏列表。
- 菜单仅显示「取消收藏」和「歌曲信息」。

#### 2.7 播放状态记忆

- 退出时保存当前歌曲、进度、播放模式。
- 下次启动恢复但不自动播放。

#### 2.8 设置

- **缓存管理**：显示封面缓存大小，可清除。
- **重置歌曲库**：清空所有歌曲、历史，停止播放。
- 帮助与关于待扩展。

#### 2.9 界面交互

- 侧边栏导航：主页、音乐库、我的最爱、播放历史、设置。
- 主页左上角抽屉图标，其他页面返回箭头。
- 返回键：主页二次确认退出；播放页返回主页；其他正常返回。
- MiniPlayer 仅主页可见。

#### 2.10 数据与性能

- Room 数据库，版本 1（正式版）。
- 封面/歌词缓存分离，增量扫描保护用户自定义数据。
- 数据库升级使用 Migration，避免破坏式迁移。

### 3. 技术栈

- Kotlin + MVVM + ViewBinding + Navigation + Material Design
- Room + MediaPlayer + Coil + 自定义 LRC 解析
- MediaStore（全盘扫描）+ SAF（自定义扫描）
